Удалённая помощь через RustDesk · редакция от 17.11.2026

Эта страница объясняет, что происходит при установке RustDesk с этого сайта, какие данные получает наш сервер и как от всего этого отказаться.

Что делает установщик

  • Скачивает официальный RustDesk (открытая программа удалённого доступа) с GitHub, а если GitHub недоступен — с нашего сервера. В Windows подпись программы проверяется перед установкой.
  • Настраивает RustDesk на наш сервер {{RDS}}, чтобы соединения шли через него, а не через общие серверы RustDesk.
  • Включает постоянный доступ. Для вашего компьютера создаётся отдельный случайный пароль, он сохраняется в RustDesk как постоянный. Благодаря ему специалист может подключиться, даже когда вас нет рядом, — например, чтобы закончить настройку или помочь ночью.
  • Обычный одноразовый пароль RustDesk тоже продолжает работать.

Какие данные получает сервер

  • ID RustDesk, имя компьютера, имя пользователя, операционная система и версия RustDesk;
  • постоянный пароль вашего компьютера (только при постоянном доступе);
  • IP-адрес и время установки, а затем — отметки «компьютер в сети» и общие сведения о системе (процессор, объём памяти), которые RustDesk сам отправляет на сервер.

Сервер не получает и не записывает содержимое экрана, файлы, переписку и нажатия клавиш. Сеансы шифруются между вашим компьютером и компьютером специалиста; сервер только помогает им найти друг друга и при необходимости пересылает зашифрованный поток.

Кто видит эти данные

Данные хранятся на нашем сервере. Доступ к ним есть только у администратора через панель, защищённую паролем. Мы не передаём их третьим лицам и не используем ни для чего, кроме удалённой помощи.

Как проходит подключение

Пока специалист подключён, RustDesk показывает на вашем экране окно сеанса. Разорвать соединение можно в любой момент кнопкой в этом окне.

Если постоянный доступ вам не нужен

Установите вариант только с одноразовым паролем: специалист сможет подключиться, только когда вы сами сообщите ему пароль из окна RustDesk, а он меняется после каждого сеанса.

Windows (.exe) macOS (.pkg) Linux (.deb)

Через терминал:
macOS — curl -fsSL {{BASE}}/mac.sh?master=0 | sudo bash
Linux — curl -fsSL {{BASE}}/linux.sh?master=0 | sudo sh

Если RustDesk уже установлен с постоянным доступом, его можно отключить самостоятельно: RustDesk → Настройки → Безопасность → Пароль → «Использовать только одноразовый пароль».

Как удалить данные

  • Удалите RustDesk с компьютера — постоянный пароль перестанет действовать.
  • Попросите специалиста, который дал вам ссылку, удалить ваш компьютер из панели: запись и пароль будут стёрты.

Cookie

Страницы загрузки не используют рекламные, аналитические и отслеживающие cookie и сами cookie не ставят.

  • Cloudflare может сохранить технический cookie (например, __cf_bm), если заподозрит автоматический трафик. Он нужен только для защиты от ботов и живёт около 30 минут.
  • Ваш ответ на уведомление о cookie хранится в браузере (localStorage), чтобы оно не показывалось снова. На сервер он не отправляется. Удалить его можно, очистив данные сайта в браузере.

Сторонние сервисы

  • GitHub — оттуда скачивается сам RustDesk;
  • Cloudflare — через него открывается эта страница;
  • ipify.org — к нему страница загрузки может обратиться, чтобы показать ваш IP-адрес.
По вопросам обращайтесь к специалисту, который прислал вам эту ссылку.
